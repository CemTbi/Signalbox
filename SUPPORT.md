# Getting help

- **Questions and ideas:** start a thread in GitHub Discussions. Search first; someone may have asked already.
- **Bugs:** open an issue with the bug report template. Include the version (`signalbox version` or `signalbox-server version`), what you did, what you expected and what happened.
- **Feature requests:** open an issue with the feature request template, starting from the problem you want solved.
- **Security vulnerabilities:** never in public. Follow [SECURITY.md](SECURITY.md).

Signalbox is maintained by volunteers and a small core team. There is no paid support. Clear reports with steps to reproduce get answered fastest.
